[JSC][Wasm] Truncate operand stack when becoming unreachable
https://bugs.webkit.org/show_bug.cgi?id=220278

Reviewed by NOBODY (OOPS!).

When validation becomes unreachable, mark the frame polymorphic and
track subsequent value-op stack effects on a type-only stack. Pop type
mismatches are rejected. End invents block results on the generator
expression stack so BBQ and IPInt stay in sync. Nested control inside
unreachable code stays counted rather than opening a real frame.

Untracked unreachable ops (GC, SIMD, atomics, br_on_*) reset the type
stack to polymorphic empty.
